# Master of the Craft, chapter 2: self-serve prompts

The owner generates these himself on a free manga tool (asked on 2026-11-09). Each prompt stands alone: it carries
the style, the people in the shot and the scene, so it works with or without reference images.

## How to run
- One image per prompt, 7 images.
- Size: 16:9 for panels 2, 3, 4, 5, 7. 3:2 for panels 1 and 6 (16:9 also fits if the tool has one size only).
- Reference images, if the tool takes them: `refs/master.jpg` and `refs/judges.jpg` for every panel,
  `refs/crinkle.jpg` for panels 1, 5, 6, 7.
- The images must come out with no text. Arabic, English and the speech bubbles are added by `render.mjs`.
- Save the results to `img/` as `full.jpg`, `eyes.jpg`, `bored.jpg`, `courses.jpg`, `door.jpg`, `bliss.jpg`,
  `smirk.jpg`, then run `node render.mjs`.
